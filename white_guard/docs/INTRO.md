## Запуск и проверки

```bash
godot --path white_guard
```

Из каталога `white_guard`:

```bash
python tools/validate_foundation.py
python tools/validate_intro.py
godot --headless --editor --import --quit --path .
godot --headless --path . --script res://tests/foundation_test.gd
godot --headless --path . --script res://tests/intro_test.gd
python tools/build_intro_preview.py /tmp/White-Guard-Intro.html
node tools/test_intro_preview.cjs /tmp/White-Guard-Intro.html /tmp/intro-check
```

Проверки подтверждают работоспособность. Они не оценивают монтаж,
естественность движения или соответствие художественному замыслу.

## Просмотр

Основная сцена `scenes/intro.tscn`. «Начать» запускает голос и изображение.
Space/Esc — пауза; управление скрывается через 2,25 секунды. Субтитры
выключены по умолчанию, при включении занимают до двух строк. При потере
фокуса просмотр останавливается, продолжение вручную. Финал предлагает повтор,
не запускает незавершённый уровень и не меняет состояние кампании.

Старый публичный просмотр с восстановленной рисовкой:
[white-guard-intro-preview](https://github.com/masterofmagic234/Kisa/releases/tag/white-guard-intro-preview).
Он сохраняет старую режиссуру с известными недостатками.
HTML из браузерного архива открывается после распаковки без интернета и сервера.
Видеосубтитры доступны отдельным SRT.

Полезная доработка экспорта сохранена: `render_intro_video.cjs` записывает
готовые 30-секундные фрагменты в `*.render-chunks/`, повторно использует их
по хешу источника и параметров, смешивает звук одной дорожкой и атомарно
заменяет итоговый MP4. Новый фильм в ходе этого отката не рендерится:
публичная PNG-демонстрация уже соответствует возвращённой постановке.
