# Вступление «Белой гвардии»

Постановка использует восстановленные PNG из `8207adb`. Новые PNG-слои
собраны из этих рисунков. Монолог Кирилла Мазура, его 12 MP3, субтитры и
дорожный фон сохранены побайтно. В озвучке 1018 слов и 472,344 секунды.

## Монтаж

- **0:00–0:21.** Три полицейские машины выходят из глубины улицы. Склейка
  на боковой проезд сохраняет направление движения, а в ближнем плане
  видны вращение колёс и опора на дорогу. Остальные группы сохраняют
  интервал в перспективе.
- **0:41–1:05.** Взгляды караульных переходят в крупный план перчатки
  у кобуры. Затем вид через стойку джипа переводит внимание на проёмы улицы.
- **1:15–1:55.** Семь мотоциклистов проходят клином. Три лимузина держат
  общую ось. В непрозрачном стекле видны только отражения улицы.
- **3:47–4:06.** Мазур поправляет хватку на бумаге. Герб, печати и подпись
  входят в кадр по монологу и остаются на экране рядом.
- **5:07–5:31.** Поворот через плечо ведёт к хвосту колонны, затем Мазур
  возвращается взглядом к обочине.
- **6:16–6:58.** Прошлое покушение отделено рамкой, тоном и пометкой
  «по рассказам». Поза на крыше и реакция караула показаны разными склейками.
- **7:49–7:52.** Мазур возвращается в кадр в паузе последней фразы.
  На `470,49` секунды монтаж переходит к лицу. На `471,39` изображение
  обрывается, затем появляется глава «Кортеж».

## Просмотр и проверка

Основная сцена `scenes/intro.tscn`. «Начать» запускает голос и изображение.
Space/Esc — пауза, при потере фокуса просмотр останавливается. Субтитры
выключены по умолчанию. Финальная карточка предлагает повтор вступления.

Из каталога `white_guard`:

```bash
godot --path .
python tools/build_intro_preview.py /tmp/White-Guard-Intro.html
```

HTML открывается в браузере без сервера и интернета. Видеоверсия использует
тот же браузерный рендерер. Экспорт сохраняет 30-секундные части, затем
собирает MP4 со звуком и отдельный SRT. Для экспорта нужны Node.js с Playwright,
Chromium и FFmpeg. Свой бинарник Chromium можно указать через `CHROMIUM_PATH`.

```bash
python tools/render_intro_video.py /tmp/White-Guard-Intro.mp4 --scratch /tmp/intro-render
python tools/validate_foundation.py
python tools/validate_intro.py
godot --headless --editor --import --quit --path .
godot --headless --path . --script res://tests/foundation_test.gd
godot --headless --path . --script res://tests/intro_test.gd
node tools/test_intro_preview.cjs /tmp/White-Guard-Intro.html /tmp/intro-check
```

`data/intro_shots.json` хранит монтаж по абсолютному времени озвучки, кадры
и координаты отдельных областей PNG. `scripts/intro_stage.gd` и
`tools/templates/intro-stage.js` читают этот таймлайн. Проезды состоят из
неподвижного рисунка улицы, общей проекции для точек опоры и отдельных
машин, упорядоченных по глубине. В боковых кадрах шаг вращения колеса
связан с пройденным расстоянием. Оригинальные атласы и производные слои
зарегистрированы в `provenance/intro-media.json`.

[Хэндофф возврата PNG](HANDOFF_INTRO_DIRECTION.md) фиксирует исходную базу
до этой постановки. [Исторический просмотр](https://github.com/masterofmagic234/Kisa/releases/tag/white-guard-intro-preview)
показывает прежний монтаж.
