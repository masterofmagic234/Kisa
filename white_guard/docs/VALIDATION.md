# Проверка подготовленной основы

## Локальные результаты

- Извлечение из Git-дерева v1.68: **58 файлов**, исходные/конечные SHA-256.
- Воспроизведение извлечения `--verify`: проверяется при доступном Arkon.
- Данные адаптации: все **11 глав** отражены в **9 эпизодах**; нет дублированных
  id или потерянных обязательных диалогов; все сюжетные уровни ещё `playable=false`.
- Godot **4.6.3 stable**, импорт проекта: без ошибок скриптов.
- Поведенческая проверка: **88 checks, 0 failures**.
- Графический просмотр: X11 / GL Compatibility / llvmpipe, три снимка:
  просмотр кампании, выбор диалога, 3D-стенд. Это визуальная проверка,
  не измерение производительности целевого устройства.
- Очистка Arkon: **37 технических заметок** перемещены в архив;
  защищённые runtime-файлы не менялись; 58 исходных хешей сверены.

## Что именно проверяется поведением

Урон и повторное попадание в период неуязвимости; единственное наступление
смерти; независимые резервы оружия; cooldown; активное время загрузки и фон;
границы субтитров при перемещении по шкале времени; последовательность реплик;
ускорение, переключение передач и торможение; clip-проекция; атомарное
сохранение и отказ от неподдерживаемой схемы; загрузка каждого runtime-модуля;
настоящий асинхронный переход план → стенд → план; физический raycast,
который наносит урон через перенесённый hitbox.

## Чего этот результат не доказывает

Человеческий AI, скоординированный штурм, окончательная модель автобуса,
актерская игра и полноценные главы пока не реализованы. Нет замеров FPS
на Windows, телефоне или PS5 и нет проверки Godot 4.7. Старые релизные
APK/ZIP не собирались заново; эта подготовка не выдаётся за новый релиз.

GitHub Actions запускает ту же основу и публикует машинный отчёт. Финальный
статус конкретного CI-запуска указывается в отчёте о передаче отдельно.
