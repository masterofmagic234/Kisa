## Открыть основу

Проверенная версия: **Godot 4.6.3 stable**, GL Compatibility.
Импортировать `white_guard/project.godot` или запустить:

```bash
godot --path white_guard
```

Основной формат: **2D топ-даун на движке третьего уровня Acorn Hunter**;
лор — простые рисованные сценки по примеру **This Is the Police**.

Просмотр прежнего плана открывается отдельно: `godot --path white_guard res://scenes/planning_room.tscn`.
В нём есть **2D стенд** и **макет сценок**. На стенде: WASD,
мышь/ЛКМ, E — дверь/добивание, Q — бросок, Shift — бег, Tab — оружие,
Esc — пауза. AI включается отдельной кнопкой. На картах стоят графические
заглушки; это не готовые люди и не глава книги. В сценках — Space/кнопка
«Далее», пропуск, Esc. Два исключения из основного игрового формата пока
оставлены на выбор автора.

## Проверить

Из каталога `white_guard`:

```bash
python tools/validate_foundation.py
godot --headless --editor --import --quit --path .
godot --headless --path . --script res://tests/foundation_test.gd
```

Повторить извлечение/проверить исходное происхождение при доступном закрытом Arkon:

```bash
python tools/extract_arkon_runtime.py /path/to/Arkon --verify
```

В `provenance/` зафиксированы источник, преобразования, хеши и адаптеры.
Личные материалы, ключи и полный текст книги не входят в проект.

Документация и стенд подготовлены для обсуждения следующей цели.
