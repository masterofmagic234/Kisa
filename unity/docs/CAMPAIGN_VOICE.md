# Голос сюжетных карточек

Текущий набор завершён: **88 MP3 / 1381 слово / 779,64 секунды**,
4 677 840 байт. Все card text SHA, audio SHA, codec и длительности повторно
проверены; оригинальные 12 intro MP3 совпадают с прежними SHA. Отчёт —
`Validation/campaign-voice.json`. Прослушивание и Unity playback ещё не
проверены; complete manifest означает готовность файлов, не native-приёмку.

Пресет совпадает с одобренным вступлением: Microsoft online TTS через
`edge-tts`, `ru-RU-DmitryNeural`, rate `-5%`, pitch `-4Hz`. Оригинальные
12 intro MP3 не перегенерируются. Runway не используется.

Генератор читает точный `card.text` из текущего `campaign.json`, не меняет его
и не исправляет произношение подменой текста. Один голос Мазура используется
для всего нового монолога. MP3 лежат в `Resources/WhiteGuardCampaign/Voice`,
имена соответствуют `card.id`. Manifest хранит voice/preset, text/audio SHA,
длительность и формат, а также явный список ещё не созданных файлов.

## Воспроизвести

Создать Python venv **вне Git**, установить
`unity/Tools/campaign-voice-requirements.txt` и доступный `ffprobe`, затем:

```text
python unity/Tools/generate_campaign_voice.py --limit 1 --concurrency 1 --attempts 1
python unity/Tools/generate_campaign_voice.py --concurrency 1 --attempts 2 --spacing 2
```

Первый отсутствующий файл всегда является последовательным сервисным probe.
Только после его успеха запускаются оставшиеся карточки. Разрешено не больше
двух workers и трёх попыток. Параметр `--limit 1` создаёт ровно один новый
файл и возвращает partial, если остальная кампания ещё не готова.

Повторный запуск переиспользует только MP3 с совпадающими text SHA, пресетом,
audio SHA и корректным codec/duration. Неподтверждённый/stale MP3 не принимается
за правильный голос. Его сначала сохранить вне Resources; затем генерировать
новый. Не оставлять старую озвучку под изменённым текстом карточки.

## Сеть и ошибки

Используются унаследованные HTTP(S) proxy и CA. У edge-tts собственный certifi
context; генератор добавляет в него предоставленный окружением CA bundle,
сохраняя проверку цепочки и hostname. TLS verification не отключается, URL с
query-token и proxy-credentials в логи не выводятся.

У сервиса в текущем запуске встречались audio-less `NoAudioReceived`, хотя
публичный voice list подтверждает DmitryNeural GA. Большая часть запросов
успешна после ограниченного повтора. После исчерпания попыток batch прекращает
новые запросы и сохраняет **partial**, а не выдаёт отсутствующие файлы за
готовые. После реального cooldown возможен явный повторный запуск с одним
worker. Ошибки auth/TLS/route не запускают циклические повторы.

Game UI должен включать новый голос глобально только при complete manifest
для всех актуальных карточек. При partial — единая текстовая подача новых
карточек; не чередовать случайно озвученные и немые главы. Голос вступления
остаётся самостоятельным и не зависит от статуса новой кампании.

Проверка MP3/длительности/хеша не заменяет прослушивание и native Unity audio
import/playback. Заикания/произношение, pause/resume/seek, skip/restart и
синхронизацию карточки с фактическим AudioSource проверять в Editor/Player.
