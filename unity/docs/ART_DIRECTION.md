# White Guard — новые материалы полной кампании

Пользователь разрешил новые качественные ассеты для полной top-down игры.
Одобренные рисунки и 12 MP3 вступления не изменялись. Новый набор продолжает
их тёплую angular painterly эстетику: геометричные формы, бумажная фактура,
ivory/ochre/olive/charcoal, Африка 1980-х без современных прицелов и брендов.

## Данные и импорт

Все новые PNG находятся в `WhiteGuard/Assets/Resources/WhiteGuardArt`.
`art-manifest.json` содержит 12 атласов и 182 crop-региона, SHA-256 исходных
PNG, фактические размеры, сетки, связи игровых стилей и сюжетных тем.
Координаты `x,y,w,h` отсчитываются от верхнего левого угла PNG. Для Unity
Sprite.Create преобразовать y как `texture.height-y-h`. Сам PNG не изменять.

Для всех новых изображений требуется lossless/uncompressed import, sRGB,
`npotScale=None`, без mipmaps. `Environment/materials.png` действительно
1254×1254, а не 1024×1024: его 16 регионов имеют измеренные границы 313/314 px.
Нельзя уменьшать текстуру при импорте и продолжать использовать прежние rects.

Actor-регионы сохраняют всю ячейку 256×256 и общий центр для анимации.
`inkBounds` — дополнительная измеренная область непрозрачного содержимого,
не отдельная отредактированная картинка. Props используют плотные crop bounds
с небольшим запасом. Все cutout-листы имеют настоящий alpha-канал и прозрачный
фон; видимый в некоторых preview коричневый RGB за alpha=0 не является фоном.
В части PNG встречается остаточная фоновая alpha 1–15/255. Проверить края в
настоящем композите: если заметен glow, исправлять через image_gen либо
обоснованный runtime alpha clip, не произвольным Python-редактированием PNG.

## Персонажи

| Атлас | Колонки | Ряды |
|---|---|---|
| `Actors/people-combat` | mazur, leon, lavrik, guard, militia, contractor | idle, walk_left, walk_right, unarmed |
| `Actors/people-story` | natalie, natalie_formal, tatiana, prince, irina, civilian_female | idle, walk_left, walk_right, crouch |
| `Actors/people-weapons` | те же шесть, что в people-combat | pistol, shotgun, bat, down |
| `Actors/people-civilians` | olongo, pankratov, doctor, chief, civilian, schoolgirl | idle, walk_left, walk_right, neutral |
| `Actors/mazur-weapon-walk` | pistol, shotgun, bat | idle, walk_left, walk_right |

`mazur-weapon-walk` — 1254×1254, сетка 3×3, ячейки 418×418. IDs, например,
`mazur_pistol_walk_left`. Два шага визуально различаются: широкий stride и
passing-step с ногами ближе друг к другу. Upper-body и оружие сохраняются;
так можно анимировать игрока без скольжения и смены пистолета на винтовку.

`Actors/mazur-carry` — отдельная прозрачная 1254×1254 картинка `mazur_carry`:
Мазур несёт полностью одетую Натали с босыми ногами. Это канонический финальный
перенос, без вымышленного пулевого ранения. При использовании скрыть отдельный
overlay-спрайт carried NPC, чтобы не изображать Натали дважды.

Каждый атлас 1536×1024, сетка 6×4. Идентификатор региона — например
`mazur_pistol`, `leon_walk_left`, `natalie_idle`, `tatiana_crouch`.
`facingClockwiseDegrees=0` означает вправо/east в изображении; 90 — вниз.
Неворужённый ряд people-combat имеет offset 90, остальные — 0. При native
проверке подтвердить ориентацию по оружию. Оружие вправо задаёт основной aim.

Для игрока с пистолетом/дробовиком/битой использовать соответствующий weapon
pose, а не rifle walk кадр. Статичный weapon pose можно дополнить небольшой
анимацией движения в Unity; не менять оружие на винтовку только ради шага ног.
Down-позы полностью одеты, без крови; ими можно сохранить читаемые тела после
смерти вместо мгновенного исчезновения противника.

Pankratov — советский политический работник/представитель, не отдельный
персонаж посла Сергея. Schoolgirl — безоружная ученица, не противник; в
actorMappings рекомендован physicalScale .75, чтобы не отображать её взрослым
солдатом. Мужские гражданские имеют свои изображения, не женский fallback.

Источник внешности Натали проверен по книге: взрослая женщина с коричневой/
светло-шоколадной кожей, чёрными волнистыми волосами, племянница президента.
В бою практичная оливковая форма, без pin-up постановки. Татьяна — золотистые
волосы; она не изображается ранним карикатурным злодеем. Мазур узнаваем по
красному берету и камуфляжу. Ирина и второстепенные лица — адаптационный дизайн,
не утверждение о каждом неописанном в тексте элементе внешности.

## Окружение

`Environment/props` — 24 cutout-предмета: автомобили/джип/автобус/грузовик,
ящики, столы, радио, диван, витрина, палатка, растения и прочее.
`Environment/mission-props` — ещё 24: launcher, generator, flowers, telephone,
hatch, flag, chair, bed, shelf, fountain, awning, cradle, cabinet, market_stall,
rubble, car_wreck, barricade, city_block, gate, ministry, rug, fallen, steps,
lamppost. Полная таблица координат — в manifest.

`launcher` — одна труба: в доме антиквара размещаются **два** экземпляра.
`cradle` — пустое деревянное корытце без ребёнка и постели, сохнущее снаружи:
наблюдение из главы 8, а не новая миссия спасения младенца.

`Environment/materials` содержит road, pavement, sand, jungle, grass, tiles,
wood, concrete, carpet, stone, plaster, fence, water, metal, dirt, marble.
Стиль `interior` соответствует tiles, `rug` — carpet, `tunnel` — stone.
Остальные alias находятся в `styleMappings`. Повторяемость текстур задумана,
но математическая бесшовность краёв не подтверждена: проверить в реальной
камере, особенно длинные поверхности и SpriteRenderer Tiled.

`convoy` использует одобренный `WhiteGuardIntro/opening-atlas-a`, quadrant 0.
Новые панели — не замена вступления, а изображения последующих эпизодов.
Карты кадров рассчитаны на crop из 768×512 в 16:9; проверить безопасные области
лиц, рук и ключевых предметов в настоящем UI.

Канон в новых изображениях: в доме видны два подготовленных launcher; Татьяна
выглядит спасённой; убийца президента не показан; финал — посольство, жёлтый
автобус и Натали с травмой ног от сапог, без вымышленного пулевого ранения.

## Граница проверки

`Validation/campaign-art.json` подтверждает размеры, alpha, SHA, уникальность
IDs, crop bounds и ссылки стилей. Все 182 региона существуют. Изображения
созданы image_gen по просмотренным одобренным референсам. Python применялся
только для анализа размеров/alpha и записи метаданных; PNG не редактировались.

Настоящий native PlayMode/GPU-прогон и художественная приёмка ещё нужны:
прочитать персонажа при игровом масштабе, проверить pivot/aim/walk, ориентацию
машин, повтор текстур, alpha edges, слои стен и кадрирование панелей.
Успех JSON/PNG-проверки не является утверждением об одобрении новой графики.
