# PS5 HFR1 · CS2 на Nuke

16 секунд офлайн-воспроизведения с 02:38 на 1×, Linux `7.2.3-ps5-hfr1`, 1080p240, системный RADV, без MP1-буста. Финальный замер дал 124,90 FPS и 69,56 FPS по 1% low (по X11 Present). Все 3998 заданий GFX сопоставлены. Потерь в tracefs не было.

В одном из пиков 16,667 мс прошло 15,986 мс от завершения предыдущей работы GFX до входа в следующий CS ioctl. Вход в ioctl → Q занял 0,187 мс. Корреляция X11 Present и GFX привязана к общим монотонным часам.

- **hfr1-nuke-final.tar.xz** — финальный захват, необработанная трасса, Present CSV, телеметрия, снимки, результаты и скрипты.
- **hfr1-nuke-comparison.tar.xz** — повтор с полной записью, в котором фоновые диагностические чтения внесли конкуренцию.
- **hfr1-nuke-preflight.tar.xz** — ранние попытки, включая захват с переполнением буфера. Служат для истории диагностики.
- **gfx-analysis.json** и **gfx-peak-scheduling.json** — результаты финального захвата.
- **SHA256SUMS** — контрольные суммы скачиваемых файлов.

В опубликованных текстовых копиях обезличены Steam ID и локальный домашний путь. Скрипт запуска сохранён как справочный снимок и использует локальную CS2, демку и вспомогательные файлы. Для анализа сохранённого захвата достаточно Python 3 и `cs2-hfr1-gfx-analyze.py` из архива.
